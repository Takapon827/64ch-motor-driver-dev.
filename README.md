# 64ch Motor Driver Board — FIELD MOTOR BOARD v1.0

I2C接続で最大64チャンネルのモーターを独立PWM制御できる基板です。

## 概要

| 項目 | 内容 |
|------|------|
| チャンネル数 | 64ch（MOT00〜MOT63） |
| 制御方式 | I2C（PWMコントローラ経由） |
| 電源 | DC 5V / 12A（センタープラス） |
| 基板層数 | 2層（1.6mm厚） |
| ツール | KiCad 9.0 |

## 回路構成

```
Host (Arduino等)
    │  I2C (SDA / SCL)
    ▼
PCA9685 × 4 (0x40 / 0x41 / 0x42 / 0x43)
    │  PWM × 64ch
    ▼
ULN2803A × 8  (Darlington Transistor Array, 8ch each)
    │  Open Collector × 64ch
    ▼
JST PH 2pin コネクタ × 64個 (MOT00〜MOT63)
    │
    ▼
モーター / ソレノイド 等
```

## 主要部品

| 部品 | 型番 | 数量 | 役割 |
|------|------|------|------|
| PWMコントローラ | PCA9685 | 4 | I2C→PWM変換、16ch/IC |
| トランジスタアレイ | ULN2803A | 8 | モータードライブ、8ch/IC |
| モーター出力コネクタ | JST PH B2B-PH-K（2ピン） | 64 | MOT00〜MOT63 |
| ポリヒューズ | PPTC 10A | 1 | 電源保護 |
| プルアップ抵抗 | 4.7kΩ | 2 | SDA / SCL |
| デカップリングコンデンサ | 100nF (0402/0805) | 12 | 各IC電源デカップリング |
| 電解コンデンサ | 100μF/10V | 2 | バルクキャパシタ |
| 電解コンデンサ | 1000μF/10V | 2 | バルクキャパシタ |
| 取り付け穴 | M3 | 4 | ボード固定用 |

## I2Cアドレス

| IC | アドレス | 制御チャンネル |
|----|----------|----------------|
| PCA9685 #1 | 0x40 | MOT00〜MOT15 |
| PCA9685 #2 | 0x41 | MOT16〜MOT31 |
| PCA9685 #3 | 0x42 | MOT32〜MOT47 |
| PCA9685 #4 | 0x43 | MOT48〜MOT63 |

基板上にはアドレス確認用テストパッドが実装されています。

## 接続

### 電源
- コネクタ: DC バレルジャック（センタープラス）
- 入力: **DC 5V / 12A**

### I2C（Arduinoヘッダ）
| ピン | 信号 |
|------|------|
| SDA | I2Cデータ |
| SCL | I2Cクロック |
| GND | グラウンド |
| +5V | 電源（ホストへ給電 or 受電） |

### モーター出力
- コネクタ: JST PH 2ピン（2.00mmピッチ）
- 出力: ULN2803A オープンコレクタ
- 最大連続電流: 500mA / ch（ULN2803A定格）

## 注意事項

> **[!] PWM MAX DUTY 25% → 1.2V avg**
>
> 各チャンネルのPWMデューティ比は最大25%を推奨します。  
> 5V電源時の平均電圧は約1.2Vとなります。  
> これを超えると部品の発熱・損傷の原因になります。

- ULN2803Aは誘導負荷（モーター）に対して内部保護ダイオードを持ちますが、大電流負荷には追加のフライバックダイオードを検討してください。
- 全チャンネル同時駆動時は電源容量（12A）に注意してください。
